# BOPE • Club Cooee

Página estática pronta para publicar no GitHub Pages.

## Arquivos

- `index.html` — página principal.
- `bope-preview.png` — imagem de destaque.

## Como colocar os links das roupas

Abra `index.html` e procure por:

- `COLOQUE_AQUI_O_LINK_DA_CAMISA_MASCULINA`
- `COLOQUE_AQUI_O_LINK_DA_CALCA_MASCULINA`
- `COLOQUE_AQUI_O_LINK_DA_CAMISA_FEMININA`
- `COLOQUE_AQUI_O_LINK_DA_CALCA_FEMININA`

Substitua cada texto pelo link real da respectiva roupa.

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html` e `bope-preview.png`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve. O GitHub vai gerar o endereço do site.

O projeto não precisa de servidor, banco de dados ou Node.js.
